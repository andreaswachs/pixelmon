# Design: NeoForge 1.21.1 + Pixelmon Modpack 9.3.16 Migration

**Date:** 2026-05-17
**Status:** Approved

## Overview

Migrate the Pixelmon Minecraft server container from Forge 1.16.5 (modpack 9.1.13) to NeoForge 1.21.1 (modpack 9.3.16). The modpack source changes from CurseForge to Modrinth, and the mod acquisition model changes from runtime download to build-time bundling.

| Aspect | Current | Target |
|---|---|---|
| Minecraft | 1.16.5 | 1.21.1 |
| Modloader | Forge | NeoForge 21.1.172 |
| Java | 8 (Temurin JRE) | 21 (Temurin JRE) |
| Server setup | Runtime (Forge installer) | Build-time (NeoForge installer) |
| Mods | Runtime download (CurseForge zip) | Build-time download (Modrinth API) |
| Mod count | ~200+ (CurseForge pack) | ~11 (Modrinth pack) |
| Configs | From CurseForge server pack | Bundled from repo |

## Architecture

**Build-time assembly:**
1. Base image `eclipse-temurin:21-jre`
2. Containerfile downloads and runs NeoForge installer (`--installServer`)
3. Containerfile downloads each mod .jar from Modrinth API into `mods/`
4. Containerfile copies default config files from repo `server-files/` into image
5. Launch script is simplified — no runtime downloads, just ConfigMap symlinking and server start

**Directory layout in image:**
```
/data/
  libraries/         # NeoForge libraries (from installer)
  mods/              # Mod JARs (from Modrinth API)
  config/            # Default mod configs (COPIED from server-files/)
  defaultconfigs/    # Default worldgen configs (COPIED from server-files/)
  resourcepacks/     # The Pixelmon OST .zip (COPIED from server-files/)
  world/             # PVC mount (empty at build)
  server-config/     # ConfigMap mount (empty at build, symlinked at runtime)
  server.properties  # Template (COPIED from server-files/)
  user_jvm_args.txt  # Generated by NeoForge installer
  unix_args.txt      # Generated by NeoForge installer
```

## Containerfile

Key changes from current:

- **Base image:** `eclipse-temurin:21-jre` (was `8-jre`)
- **Build deps:** Adds `jq` for parsing Modrinth API JSON responses
- **NeoForge installer:** Downloads from `maven.neoforged.net`, runs `--installServer /data`
- **Mod downloads:** 10 mod JARs fetched via `api.modrinth.com/v2/version/{VERSION_ID}`, saved to `/data/mods/`
- **Configs:** `COPY server-files/` into `/data/config/`, `/data/defaultconfigs/`, `/data/resourcepacks/`
- **Labels:** Updated to version `9.3.16`

## Launch Script

Simplified from current:

- **Removed:** CurseForge zip download, unzip, `Install.sh`, `server-setup-config.yaml` editing, `settings.sh` sourcing, `$MAX_RAM` support, `$OPS` support
- **Removed:** Old cleanup of `configs/`, `kubejs/`, `forge-*.jar`, etc.
- **Kept:** ConfigMap symlinking (server.properties, ops.json, whitelist.json, banned-ips.json, banned-players.json), EULA handling, MOTD, server-port, level-name
- **Launcher:** Uses NeoForge standard `java @user_jvm_args.txt @libraries/net/neoforged/neoforge/21.1.172/unix_args.txt nogui`

## Config Files

Bundled via `server-files/` directory committed to repo:

```
server-files/
  server.properties  # Template with default values
  config/            # Mod config .toml/.json files
  defaultconfigs/    # Default worldgen configs
  resourcepacks/     # The Pixelmon OST .zip
```

Copied into image at build time. Runtime ConfigMap mounts override at `/data/server-config/`.

## Image Metadata (image.yaml)

```yaml
name: pixelmon
version: 9.3.16-1
registry: oci://ghcr.io/andreaswachs/pixelmon
platforms: linux/arm64
```

## CI/CD

No changes needed to `.github/workflows/release.yaml` — it reads `image.yaml` dynamically and builds whatever `Containerfile` is in-tree.

## Removed Features

- `$MAX_RAM` env var support — users configure JVM args via `user_jvm_args.txt` ConfigMap
- `$OPS` env var support — users configure operators via `ops.json` ConfigMap
